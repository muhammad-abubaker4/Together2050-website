# TOGETHER2050

## Official Website — Master Development Brief

Build the official website for **Together2050**.

The website must present Together2050 as a serious, credible, long-term platform — not as a generic youth organization, startup landing page, NGO template, or overly corporate website.

The central identity is:

> **Together, We Create What Matters.**

Together2050 is built around a simple idea: meaningful progress happens when people, ideas, and opportunities come together.

The website should communicate this clearly through its design, content, structure, and interactions.

---

## Organization Name

**Together2050**

## Tagline

**Together, We Create What Matters.**

## Core Description

> A platform that brings people, ideas, and opportunities together to learn, collaborate, contribute, and create meaningful progress toward 2050 and beyond.

## Established

**14 August 2026**

**2 September 2026**

Do not invent additional organizational claims, statistics, achievements, members, partnerships, impact numbers, awards, or history.

# 2. WEBSITE OBJECTIVE

The website should answer five basic questions immediately:

1. What is Together2050?
2. Why does Together2050 exist?
3. What does Together2050 actually do?
4. Who is behind it?
5. How can someone connect, contribute, collaborate, or become involved?

The website should feel:

* Human
* Clear
* Serious
* Modern
* Purpose-driven
* Long-term
* Community-oriented
* Credible
* Minimal
* Confident

Avoid:

* Generic NGO aesthetics
* Excessive animations
* Fake statistics
* Stock-photo-heavy layouts
* Corporate buzzwords
* "Revolutionary", "game-changing", "transformative ecosystem" type language
* Artificial urgency
* Excessive gradients
* Excessive glassmorphism
* AI-generated-looking design
* Unnecessary sections
* Invented information

The website should communicate substance rather than trying to look impressive.

# 3. VISUAL IDENTITY

## Primary Colors

The finalized visual direction is based on:

**Red + Black + Warm Off-White**

Use the red as the primary accent rather than filling the entire website with red.

Suggested hierarchy:

* Deep black / near-black — primary background
* Warm off-white — primary text/light sections
* Signature red — accents, buttons, highlights, active states
* Muted neutral tones — secondary text and borders

Do not introduce unrelated brand colors.

## Design Direction

The visual language should be:

**Editorial + Institutional + Modern**

Think of a serious organization that intends to exist for decades rather than a trendy startup.

Use:

* Strong typography
* Large editorial headlines
* Generous whitespace
* Clear hierarchy
* Sharp alignment
* Restrained motion
* Strong black/white contrast
* Red used strategically
* Subtle borders
* Carefully designed cards
* Clean navigation

The website should look excellent on desktop and mobile.

---

# 4. TYPOGRAPHY

Use a professional modern sans-serif typeface.

Typography hierarchy should be obvious:

### Hero

Large, bold, confident.

### Section headings

Strong but not oversized.

### Body

Highly readable with comfortable line height.

### Supporting text

Muted but accessible.

Avoid using too many font families.

Use one primary typeface with different weights unless there is a strong design reason otherwise.

# 23. ANIMATION

Use animation carefully.

Allowed:

* Fade/slide reveals
* Subtle text movement
* Hover states
* Smooth section transitions
* Navigation transitions
* Gentle scrolling effects
* Small red accent movements
* Subtle 2050 visual animation

Avoid:

* Excessive parallax
* Constant floating elements
* Spinning logos
* Excessive particle effects
* Every element animating independently
* Slow transitions that make the website feel sluggish

Animation must support the message rather than distract from it.

Respect `prefers-reduced-motion`.
